COLOR LEGEND:
  ● Green:  running - Device is actively processing
  ● Yellow: waiting_to_start - Initialization wait state
  ● Orange: waiting_to_exit - Shutdown wait state  
  ● Red:    failed - Device has encountered a failure
  ● Gray:   exited - Device has completed shutdown
  ● Pink:   interrupted - Device was interrupted
